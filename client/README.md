# @refactor-circus/showroom-client

A typed fetch client for Showroom's JSON API, built on [openapi-fetch](https://openapi-ts.dev/openapi-fetch/). Its types are generated by [openapi-typescript](https://openapi-ts.dev/) from the package's `openapi.json`, so every path, query parameter, request body and response is checked by TypeScript.

The client is not published to a registry. Install it from the Showroom repository at a release tag; `dist/` is committed, so it needs no build step. npm cannot install a subfolder of a git repository, so use pnpm or Yarn:

```sh
pnpm add "github:Refactor-Circus/Showroom#v2.0.0&path:client"
```

## Usage

```ts
import { createShowroomClient } from '@refactor-circus/showroom-client';

const showroom = createShowroomClient({
  // The URL of the host's `showroom.routes.prefix`.
  baseUrl: 'https://app.test/showroom',
  // Optional: sent with every request.
  headers: { Accept: 'application/json' },
  // Optional: send the session cookie to a session-authenticated host.
  credentials: 'include',
});

const { data: stats } = await showroom.GET('/stats');
console.log(stats?.data.status.counts.in_review);

const { data: results, error } = await showroom.GET('/search', {
  params: { query: { q: 'sku-1', type: 'products', limit: 10 } },
});

const { data: product } = await showroom.GET('/products/{product}', {
  params: { path: { product: 'SKU-1' } },
});
```

`createShowroomClient({ baseUrl, headers?, fetch?, credentials? })` returns openapi-fetch's `Client<paths>`. The generated types are exported too:

```ts
import type { components, operations, paths } from '@refactor-circus/showroom-client';

type Stats = operations['showroom.stats.show']['responses'][200]['content']['application/json']['data'];
type Product = components['schemas']['ProductResource'];
```

Each operation is named after its Laravel route (`showroom.stats.show`, `showroom.search.index`, `showroom.settings-summary.show`, ...).

## Regenerating

Never edit `src/schema.d.ts` or `dist/` by hand. From the package root, after changing a route, request rule, Data `rules()` or resource:

```sh
composer client:generate
```

It exports `openapi.json` with Scramble, then runs `npm --prefix client ci` and `npm --prefix client run generate`: openapi-typescript writes `src/schema.d.ts`, `scripts/stamp.mjs` stamps its first line with the sha256 of `openapi.json` and copies it to `dist/schema.d.ts`, and `tsc` builds `dist/`. Commit `openapi.json` and every changed file under `client/`. `tests/OpenApi/OpenApiTest.php` fails while either is stale.
